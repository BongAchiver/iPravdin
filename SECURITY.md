# Свойства безопасности iPravdin 2.6.0

Дата: 4 октября 2026 года. Проверены исходники в `app`, конфигурация и готовый архив; сведения о зависимостях ниже относятся к проверке 3 октября. Это проверка кода и поведения на тестовой странице, а не независимый аудит или гарантия отсутствия всех уязвимостей.

## Результат

В финальном коде не обнаружены сбор паролей, чтение форм, отправка истории, аналитика, загрузка удалённого кода, исполнение строк как JavaScript, обфускация или передача содержимого страниц. Нет `fetch`, XMLHttpRequest, WebSocket, `eval`, `innerHTML` и внешних скриптов. Обработчики runtime-сообщений обслуживают локальную игру; награды начисляются последовательно в background, ответы и поимки привязаны к ID встречи и вкладке, завершение пряток — к адресу статьи и ID квеста. DOM изменяется для изображений и собственного интерфейса.

Mozilla Add-ons Linter в режиме `--self-hosted`: **0 ошибок, 0 предупреждений, 0 замечаний**. После добавления `web-ext@10.7.0` для подписи `npm audit` сообщает о **3 связанных dev-пакетах с уровнем high**: `web-ext` → `@devicefarmer/adbkit` → `node-forge@1.4.0`, advisory [GHSA-86w9-cpqp-85rv](https://github.com/advisories/GHSA-86w9-cpqp-85rv). Уязвимость относится к проверке RSA-подписей в зависимости инструмента Android; исправленная версия node-forge на момент проверки недоступна в npm. Предлагаемый npm откат web-ext до 5.x не применяется. Runtime-зависимостей npm нет: `node_modules` не попадает в XPI. Эти результаты относятся к дате проверки.

Автообновление добавляет HTTPS-запросы самого Firefox к GitHub за `updates.json` и подписанным XPI. Скрипты расширения по-прежнему не отправляют сетевых запросов. API-ключи Mozilla нужны только инструменту подписи и хранятся в GitHub Actions Secrets или переменных окружения; в исходники и пакет они не входят.

## Найдено и исправлено

| Проблема исходника | Риск / последствие | Изменение |
| --- | --- | --- |
| Подмена `img.src` внешними HTTP-фотографиями | Подмена контента в сети, mixed content, раскрытие IP/Referer сторонним серверам, неработающие ссылки | Только локальные фотографии из XPI, никаких сетевых загрузок подмены |
| Широкое разрешение `tabs` | Избыточный доступ к метаданным вкладок | Удалено; настройки открываются через `runtime.openOptionsPage` |
| Настройки через `storage.sync` | Передача настроек через синхронизацию аккаунта | Только `storage.local` |
| Неограниченные повторные попытки при битых фотографиях | Циклы ошибок, пустой список фотографий | Фиксированная локальная подборка; при ошибке возврат оригинала без повторного цикла |
| Опрос всего DOM каждые 3 секунды | Постоянная нагрузка на большие страницы | MutationObserver, объединение изменений в кадр, отключение наблюдателя во время собственных записей |
| Выключение не восстанавливало страницу | Подменённый контент оставался видимым | Восстановление адресов, responsive-источников и изменённых свойств стиля |
| Chrome service worker в Firefox | Фоновая часть не запускалась | Непостоянная событийная фоновая страница MV3 с `background.scripts` |
| Старые инструменты сборки; уязвимые транзитивные зависимости | Риски среды разработки | Удалён Grunt/Babel; актуальный Mozilla Linter, отдельная ZIP-сборка, lock-файл. Состояние Android-зависимости web-ext описано выше |
| Старый HTML-тест с удалённым jQuery | Устаревший сторонний исполняемый код | Удалён из распространяемого пакета; тестовые страницы полностью локальные |

Документация Firefox: [background в Manifest V3](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/manifest.json/background), [декларация сбора данных](https://extensionworkshop.com/documentation/develop/firefox-builtin-data-consent/).

## Разрешения и данные

| Разрешение / ресурс | Зачем нужен |
| --- | --- |
| `storage` | Переключатели, домены исключений, настроение, зачётка, коллекция и текущие встречи/квесты |
| `contextMenus` | Контекстное меню включения/выключения и открытия настроек |
| HTTP/HTTPS host permissions | Замена изображений, игровые окна и фотография квеста на обычных веб-страницах |
| `web_accessible_resources`: `photos/*.jpg`, `collectibles/*.jpg`, `reactions/*.jpg`, `game.css` | Локальные фотографии, 15 иллюстраций, реакции портрета и оформление игрового окна в изолированном shadow DOM |

Список исключений и игровой прогресс не покидают браузер. Кнопки пряток открывают статьи Википедии в обычных вкладках; сайт получает обычный запрос браузера. Игра не запрашивает внешний API и не сохраняет историю посещений. Разрешения cookies, history, webRequest, downloads, clipboard, nativeMessaging и tabs не запрашиваются. Сбор и передача данных декларируются как `none`. Внутри настроек применяется CSP с запретом внешних подключений, inline-скриптов, плагинов и отправки форм. Домены проверяются; вывод через `textContent` исключает интерпретацию HTML.

## Оставшиеся свойства и границы

- Доступ к DOM всех HTTP/HTTPS сайтов необходим для автоматической замены и остаётся широким. Пользователь может ограничить доступ в Firefox. Не устанавливайте непроверенные модификации с такими разрешениями.
- Страница может увидеть изменённый `img.src` и определить, что изображения подменяются. Локальные фотографии доступны странице через явно объявленные ресурсы; настройки, скрипты и другие страницы расширения через WAR не раскрыты.
- Оригинальные сайты сами продолжают выполнять свои сетевые запросы, включая загрузку исходных изображений до подмены и при восстановлении. Расширение не блокирует сетевые запросы страницы.
- Замена способна скрыть значимый контент, в том числе QR-коды. Для таких сайтов используйте исключения или выключение. CSS-фоны, shadow DOM и canvas не обрабатываются.
- Полный браузерный сценарий выполнен на Firefox 157.0 Windows. Минимальная версия 140 проверена по API и манифесту через Linter, без отдельного запуска Firefox 140. Android и все произвольные сайты отдельно не проверялись.
- Локальная сборка XPI не подписана. GitHub Actions подписывает публикуемый XPI через Mozilla; пакет из Releases можно установить постоянно.

При обновлении удаляются сохранённые данные удалённой функции расписания: токены, кэш и временные параметры входа. Настройки изображений сохраняются.

## Проверки

36 автоматических тестов проверяют подмену и восстановление изображений, настройки, обновления, игровую логику, миграцию интервала, шансы событий, привязку карточки к вкладке и однократность награды, а также видимую ошибку запуска учебной страницы. Для банка из 404 вопросов и 305 реплик проверяются корректность структуры, численные ответы вычислительных задач, отсутствие повторов в цикле, сохранение порядка между запусками и билет на границе циклов. Колоды вопросов и реплик хранятся локально вместе с прогрессом.

Коллекционные карточки используют локальные токены с ограниченным сроком жизни и проверкой вкладки в background. Перехват клика действует только на активную карточку и предотвращает переход по ссылке сайта при её сборе. Режим отладки и его настройки сохраняются локально; принудительные события доступны из страниц самого расширения и не требуют новых разрешений. Учебная страница передаёт свой ID вкладки, который background сверяет с адресом отправителя.

Selenium-сценарий устанавливает готовый ZIP в отдельный Firefox-профиль и проверяет декодирование локального изображения, `<picture>`, `srcset`, iframe, динамический DOM, выключение через реальные элементы интерфейса, исходные стили, бейдж OFF, добавление/удаление исключения, выключение защиты маленьких изображений, popup и темы. Тестовый флаг geckodriver `--allow-system-access` используется только для автоматизации страницы настроек в одноразовом профиле; расширение такого доступа не имеет.

Также проверяются подготовка обновлений, возрастающие версии для CI и удаление оставшихся данных прежней авторизации без изменения настроек.

Для повторения: `npm ci`, `npm test`, `npm run lint`, `npm audit`, `npm run build`, `npm run test:firefox`.
