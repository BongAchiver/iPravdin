# Проверка безопасности iPravdin 2.1.0

Дата: 3 октября 2026 года. Проверены исходники в `app`, конфигурация, зависимости сборки и готовый архив. Это проверка кода и поведения на тестовых страницах, а не независимый аудит или гарантия отсутствия всех уязвимостей.

## Результат

Расширение не читает формы входа, пароли, токены, историю или cookie-хранилище. Нет аналитики, загрузки удалённого кода, `eval` или `innerHTML`. Для расписания используется существующий Axios-клиент открытой страницы my.itmo: запрос идёт только к персональному API ИТМО, а авторизацией управляет сам сайт. Внутреннее сообщение от popup вызывает запрос фиксированного ресурса за одну проверенную дату; произвольный адрес, аккаунт или идентификатор студента передать нельзя.

Обработчик работает только в верхнем фрейме точного origin `https://my.itmo.ru`. Сообщения принимаются только от страниц того же расширения. Через Firefox `wrappedJSObject` читаются клиент страницы и номер ИСУ; через `cloneInto` передаётся только объект таймаута. Привилегированные функции расширения в страницу не экспортируются. Возвращаются только нормализованные поля пар, номер ИСУ и время обновления; исходные ошибки Axios, конфигурация запросов и заголовки не передаются. При смене аккаунта в ходе запроса результат отбрасывается.

Mozilla Add-ons Linter в режиме `--self-hosted`: **0 ошибок, 0 предупреждений, 0 замечаний**. После добавления `web-ext@10.7.0` для подписи `npm audit` сообщает о **3 связанных dev-пакетах с уровнем high**: `web-ext` → `@devicefarmer/adbkit` → `node-forge@1.4.0`, advisory [GHSA-86w9-cpqp-85rv](https://github.com/advisories/GHSA-86w9-cpqp-85rv). Уязвимость относится к проверке RSA-подписей в зависимости инструмента Android; исправленная версия node-forge на момент проверки недоступна в npm. Предлагаемый npm откат web-ext до 5.x не применяется. Runtime-зависимостей npm нет: `node_modules` не попадает в XPI. Эти результаты относятся к дате проверки.

Автообновление добавляет HTTPS-запросы самого Firefox к GitHub за `updates.json` и подписанным XPI. Расписание запрашивается клиентом страницы только у my.itmo. API-ключи Mozilla нужны только инструменту подписи и хранятся в GitHub Actions Secrets или переменных окружения; в исходники и пакет они не входят.

## Найдено и исправлено

| Проблема исходника | Риск / последствие | Изменение |
| --- | --- | --- |
| Подмена `img.src` внешними HTTP-фотографиями | Подмена контента в сети, mixed content, раскрытие IP/Referer сторонним серверам, неработающие ссылки | Только локальные фотографии из XPI, никаких сетевых загрузок подмены |
| Широкое разрешение `tabs` | Избыточный доступ к метаданным вкладок | Удалено; настройки открываются через `runtime.openOptionsPage` |
| Настройки через `storage.sync` | Передача настроек через синхронизацию аккаунта | Только `storage.local` |
| Неограниченные повторные попытки при битых фотографиях | Циклы ошибок, пустой список фотографий | Фиксированная локальная подборка; при ошибке возврат оригинала без повторного цикла |
| Опрос всего DOM каждые 3 секунды | Постоянная нагрузка на большие страницы | MutationObserver, объединение изменений в кадр, отключение наблюдателя во время собственных записей |
| Выключение не восстанавливало страницу | Подменённый контент оставался видимым | Восстановление адресов, responsive-источников и изменённых свойств стиля |
| Chrome service worker в Firefox | Фоновая часть не запускалась | Непостоянная событийная фоновая страница MV3 с `background.scripts` |
| Старые инструменты сборки; уязвимые транзитивные зависимости | Риски среды разработки | Удалён Grunt/Babel; актуальный Mozilla Linter, отдельная ZIP-сборка, lock-файл. Состояние Android-зависимости добавленного для подписи web-ext описано выше |
| Старый HTML-тест с удалённым jQuery | Устаревший сторонний исполняемый код | Удалён из распространяемого пакета; тестовые страницы полностью локальные |

Документация Firefox: [background в Manifest V3](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/manifest.json/background), [декларация сбора данных](https://extensionworkshop.com/documentation/develop/firefox-builtin-data-consent/).

## Разрешения и данные

| Разрешение / ресурс | Зачем нужен |
| --- | --- |
| `storage` | Локальные переключатели и явно добавленные пользователем домены исключений |
| `contextMenus` | Контекстное меню включения/выключения и открытия настроек |
| HTTP/HTTPS host permissions | Доступ к DOM изображений; выбор доступной вкладки my.itmo и обмен сообщениями с её скриптом |
| `web_accessible_resources` только `photos/*.jpg` | Отображение двух локальных фотографий Правдина в элементах сайтов |

Список исключений не покидает браузер. Расписание и номер ИСУ не записываются в storage: они остаются только в памяти popup. Разрешения cookies, history, webRequest, downloads, clipboard, nativeMessaging и tabs не запрашиваются. Сбор разработчиком и передача данных за пределы сайта-источника отсутствуют и декларируются как `none`. Внутри настроек применяется CSP с запретом внешних подключений, inline-скриптов, плагинов и отправки форм. Запрос расписания выполняется клиентом самого my.itmo в контексте страницы. Даты проверяются; вывод пар через `textContent` исключает интерпретацию HTML сайта.

## Оставшиеся свойства и границы

- Доступ к DOM всех HTTP/HTTPS сайтов необходим для автоматической замены и остаётся широким. Пользователь может ограничить доступ в Firefox. Не устанавливайте непроверенные модификации с такими разрешениями.
- Страница может увидеть изменённый `img.src` и определить, что изображения подменяются. Локальные фотографии доступны странице через явно объявленные ресурсы; настройки, скрипты и другие страницы расширения через WAR не раскрыты.
- Оригинальные сайты сами продолжают выполнять свои сетевые запросы, включая загрузку исходных изображений до подмены и при восстановлении. Расширение не блокирует сетевые запросы страницы.
- Замена способна скрыть значимый контент, в том числе QR-коды. Для таких сайтов используйте исключения или выключение. CSS-фоны, shadow DOM и canvas не обрабатываются.
- Полный браузерный сценарий выполнен на Firefox 157.0 Windows. Минимальная версия 140 проверена по API и манифесту через Linter, без отдельного запуска Firefox 140. Android и все произвольные сайты отдельно не проверялись.
- XPI не подписан Mozilla. Подпись и проверка при публикации остаются отдельным этапом.

## Проверки

21 автоматический тест проверяет изображения, подготовку обновлений и выбор возрастающих версий для CI, московские даты и границы пары, нормализацию расписания, независимые аккаунты, смену аккаунта во время запроса, отсутствие чтения токенов, очистку данных при выходе, запрет запросов от страницы и безопасный вывод HTML как текста.

Selenium-сценарий устанавливает готовый ZIP в отдельный Firefox-профиль и проверяет декодирование локального изображения, `<picture>`, `srcset`, iframe, динамический DOM, выключение через реальные элементы интерфейса, исходные стили, бейдж OFF, добавление/удаление исключения, выключение защиты маленьких изображений, popup и темы. Тестовый флаг geckodriver `--allow-system-access` используется только для автоматизации страницы настроек в одноразовом профиле; расширение такого доступа не имеет.

Отдельный Selenium-сценарий расписания копирует пакет в временную папку и заменяет только origin на локальный тестовый сервер; производственный пакет остаётся привязан к my.itmo. Он проверяет настоящую границу между скриптом расширения и Nuxt/Axios-клиентом страницы в Firefox. Реальный вход и персональное расписание ИТМО не проверялись.

Для повторения: `npm ci`, `npm test`, `npm run lint`, `npm audit`, `npm run build`, `npm run test:firefox`, `npm run test:firefox:schedule`.
